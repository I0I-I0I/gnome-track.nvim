1. Introduction					*gnome-track-intro*

gnome-track is a minimal plugin that tracks the GNOME desktop color-scheme
preference (`gsettings org.gnome.desktop.interface color-scheme`) and fires a
callback whenever it changes. Handy for syncing your colorscheme / terminal
opacity with the desktop light/dark toggle.

The scheme is one of: "prefer-dark", "prefer-light", "default".

==============================================================================
3. API							*gnome-track-api*

setup({opts})						*gnome-track.setup()*
	Accepts a config table or a callback function.

	Table options:
	    callback	Callable fired with the current scheme on startup and on
			every change.
	    notify	Emit an INFO notification on each change (default: true).

track({cb})						*gnome-track.track()*
	Register a callback and start tracking. Calling it again re-registers
	the callback if tracking is already active.

stop()							*gnome-track.stop()*
	Stop the gsettings monitor and clear all callbacks.
